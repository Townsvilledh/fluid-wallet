# Scan

The **Scan** tab answers one question: *what is public on-chain for this
name or address?*

- Paste a **Fluid name** or a **wallet address** and Scan shows the
  public on-chain picture for the registered addresses behind it —
  balances across the chains the name is registered on.
- A pasted **transaction id** opens the matching chain view for that
  transaction.
- Privacy rule, stated in the tab itself: *Scan shows what is public
  on-chain for a name's registered addresses. Unregistered addresses
  stay private.* A Fluid name publishes only the addresses its owner
  claimed with it (`names.README.md`); nothing else about a wallet is
  exposed by Scan.
