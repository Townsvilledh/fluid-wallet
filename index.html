⚽ Fluid

Your money, only you control. A simple, open-source, non-custodial Web3 wallet. Keys are created and encrypted in this browser — Fluid has no server and can never touch your funds.

Open-source prototype. Built on the audited ethers.js library, but the app itself is unaudited. Start on Sepolia testnet or with small amounts, back up your seed, and verify the code — it's all on GitHub.

Backup & safety

Recovery without Fluid: import your seed into MetaMask / Trust Wallet / any BIP39 wallet, or use the Fluid 2-of-4 recovery tool. If Fluid disappears tomorrow, your funds don't.

Fluid is free and open source (MIT). No accounts, no tracking, no server. Verify: view source / GitHub.
